Node.js CLI calculator

This simple calculator implements the four basic operations shown in the provided image:
- addition (+)
- subtraction (-)
- multiplication (× or *)
- division (÷ or /)

Usage:
  node src/cli.js <number> <operator> <number>

Examples:
  node src/cli.js 2 + 3
  node src/cli.js 10 / 4
